# Sprint 1 — Field Editor Foundation

**Текущий спринт:** Sprint 1

**Дата начала:** 2026-07-09

**Статус:** В процессе

## Цель

Пользователь запускает приложение, создает новый документ, загружает изображение поля, свободно перемещает и масштабирует его, а затем сохраняет документ проекта (.ptf).

## Критерии готовности

1. Приложение запускается
2. Можно создать новый документ
3. Можно открыть PNG/JPG изображение
4. Работает панорамирование (Pan)
5. Работает масштабирование (Zoom)
6. Отображается панель слоёв с Image слоем
7. Можно сохранить документ (.ptf)
8. Можно загрузить документ (.ptf)
