# Terminology

## Основные термины
- Layout - макет поля
- Bunker - укрытие
- Player - игрок
- Scenario - сценарий
- Ray - луч
- Sector - сектор
- Camera - камера
- Editor - редактор

## Термины пейнтбола
- Field - поле
- Flag - флаг
- Elimination - выбывание
- Breakout - начальная расстановка
- Movement - перемещение

## Модули src/
- core - ядро
- editor - редактор
- ui - интерфейс
- import - импорт
- geometry - геометрия
- scenario - сценарии
- io - ввод/вывод
