# ADR-0003: Undo/Redo откладывается

**Дата:** 2026-07-09
**Статус:** Принято

## Контекст

Необходимо определить, когда реализовывать систему Undo/Redo.

## Решение

Отложить до Sprint 6.

## Причина

1. Сначала должны быть стабильны все основные операции
2. Undo/Redo должен строиться на паттерне Command
3. Преждевременная реализация приведёт к переделкам

## План

Sprint 6 — Command System
- Паттерн Command
- Undo / Redo
- История изменений
- Основа для Replay

## Альтернативы

Альтернатива 1: Реализовать сейчас
- ❌ Преждевременная оптимизация
- ❌ Большая вероятность переделок

## Последствия

- ✅ Стабильная архитектура
- ✅ Единый подход ко всем операциям
- ✅ Автоматическое решение для Replay
