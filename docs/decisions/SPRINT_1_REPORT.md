## 4. Изменения архитектуры (ADR)

### ADR-001: Entity и Token модель

**Причина:** Необходима гибкая система объектов

**Решение:** Entity (база) → Token (подвижный объект)

**Плюсы:** Гибкость, расширяемость

### ADR-002: Система слоёв

**Причина:** Удобство работы с разной информацией

**Решение:** Слои как в Photoshop (видимость, блокировка)

**Плюсы:** Киллер-фича, удобство

---

## 5. Изменения модели данных

- Document — главный контейнер проекта
- Layer — слой с видимостью и блокировкой
- Camera — зум и панорамирование
- Entity — базовый объект
- Token — подвижный объект (игрок, судья, камера)
