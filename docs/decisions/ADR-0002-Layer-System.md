# ADR-0002: Система слоёв

**Дата:** 2026-07-09
**Статус:** Принято

## Контекст

Необходимо организовать отображение разных типов информации на поле.

## Решение

Использовать систему слоёв как в Photoshop.

**Стандартные слои:**
1. Image — всегда внизу, заблокирован
2. Geometry — бункеры
3. Players — игроки (Token)
4. Rays — линии
5. Movement — траектории
6. Control — зоны контроля
7. Comments — заметки

## Альтернативы

### Альтернатива 1: Всё в одном слое
- ❌ Нельзя выключить
- ❌ Сложно редактировать

### Альтернатива 2: Отдельные сцены
- ❌ Сложно переключать
- ❌ Проблемы с производительностью

## Последствия

- ✅ Удобство работы
- ✅ Гибкость
- ✅ Киллер-фича проекта
