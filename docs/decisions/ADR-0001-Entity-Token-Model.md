# ADR-0001: Entity и Token модель

**Дата:** 2026-07-09
**Статус:** Принято

## Контекст

Необходимо определить, как будут представлены объекты на поле.

## Решение

Ввести два уровня абстракции:

1. **Entity** — базовый класс для всех объектов
2. **Token** — наследник Entity, представляющий подвижный объект

## Альтернативы

### Альтернатива 1: Только Player
- ❌ Негибко
- ❌ Сложно добавить судью, камеру

### Альтернатива 2: Только Entity
- ❌ Слишком абстрактно
- ❌ Нет типизации

## Последствия

- ✅ Гибкость
- ✅ Расширяемость
- ✅ Единообразие
