# ADR-0005: Структура Project и Document

**Дата:** 2026-07-09
**Статус:** Принято

## Контекст

Необходимо определить, как организованы проекты и документы.

## Решение

Paintball Project/
    layouts/        # .ptf файлы
    images/         # PNG/JPG изображения
    exports/        # Экспортированные файлы
    scenarios/      # Сценарии

## Структура

- Project — папка с проектом
- Document (.ptf) — один тактический документ
- Scenario — сценарий внутри документа

## Преимущества

1. Один проект = несколько сценариев для одного поля
2. Все ресурсы в одном месте
3. Удобно для командной работы

## Пример

RXL_Moscow_2026/
    images/
        field.png
    layouts/
        final.ptf
        semifinal.ptf
    exports/
        final.pdf
    scenarios/
        attack.scn
        defense.scn

## Последствия

- ✅ Организованность
- ✅ Масштабируемость
- ✅ Удобство работы
