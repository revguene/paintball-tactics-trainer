# ADR-0004: Изображения хранятся отдельно от .ptf

**Дата:** 2026-07-09
**Статус:** Принято

## Контекст

Необходимо определить, как хранить изображения полей.

## Решение

.ptf хранит только ссылку на изображение, а не само изображение.

RXL_Moscow/
    Layout.png      # Изображение
    Layout.ptf      # Документ со ссылкой

## Причины

1. Маленький размер .ptf
2. Можно заменить изображение без изменения документа
3. Git хранит изменения эффективнее
4. Удобно обмениваться проектами

## Два режима работы

### Режим разработки
Layout.ptf + Layout.png (отдельно)

### Режим публикации
Layout.ptz (архив)
Внутри: Layout.ptf + Layout.png + preview.png + metadata.json

## Формат .ptf

{
  "version": 1,
  "image": "Layout.png",
  "layers": [],
  "camera": {}
}

## Последствия

- ✅ Простота
- ✅ Гибкость
