# Paintball Tactics Trainer

Интерактивный тренажёр для отработки тактических схем в пейнтболе.

## Структура проекта

```
paintball-tactics-trainer/
├── .github/          # GitHub конфигурации (issues, workflows)
├── .cursor/          # Правила для Cursor AI
├── assets/           # Игровые ресурсы (текстуры, звуки, иконки)
├── data/             # Данные игры (конфигурации, уровни)
├── docs/             # Документация
├── scenes/           # Сцены Godot
├── scripts/          # Скрипты GDScript
├── tests/            # Тесты
└── project.godot     # Файл проекта Godot
```

## Требования

- Godot 4.x

## Установка

1. Клонируйте репозиторий
2. Откройте проект в Godot
3. Наслаждайтесь!
